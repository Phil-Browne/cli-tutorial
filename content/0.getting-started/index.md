# Getting Started

Welcome to the Megaport CLI tutorial. This guide will walk you through everything you need to manage Megaport network infrastructure from the command line.

## What is the Megaport CLI?

The Megaport CLI is a powerful command-line tool for managing Megaport resources including Ports, VXCs, MCRs, MVEs, and more.
