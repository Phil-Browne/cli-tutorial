# Quick Demo (No Login)

Try the CLI right now — no credentials needed. The commands below query public Megaport data (locations and partner ports). Type them directly into the terminal.

## Commands to try

These commands work **without authentication** and query live data from the Megaport API:

```bash
# Check CLI version
megaport-cli version

# Browse 800+ data centre locations worldwide
megaport-cli locations list

# Filter to a specific metro
megaport-cli locations list --metro Sydney

# Find locations where MCR is available
megaport-cli locations list --mcr-available

# List cloud partner ports (AWS, Azure, GCP, etc.)
megaport-cli partners list

# Filter to a specific provider
megaport-cli partners list --company-name "Amazon Web Services"

# JSON output for automation
megaport-cli locations list --output json
```

::info-card{type="tip" title="Want to do more?"}
Commands that manage resources (`ports list`, `vxc create`, etc.) require authentication. Head to the [Browser Terminal](/demos/browser-terminal) to connect with your Staging API key.
::
