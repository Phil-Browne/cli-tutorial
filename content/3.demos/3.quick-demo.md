## Commands to try

These commands work **without authentication** and query live data from the Megaport API:

```bash
# Browse 800+ data centre locations worldwide
megaport-cli locations list

# Filter to a specific metro
megaport-cli locations list --metro Sydney

# Find locations where MCR is available
megaport-cli locations list --mcr-available

# JSON output for automation
megaport-cli locations list --output json
```

::info-card{type="tip" title="Want to do more?"}
Commands that manage resources (`ports list`, `vxc buy`, etc.) or query partners require authentication. Head to the [Browser Terminal](/demos/browser-terminal) to connect with your Staging API key.
::
