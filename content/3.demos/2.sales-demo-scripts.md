# Sales Demo Scripts

Four scripts matched to meeting length and audience. All commands work with a Staging account — no credentials needed from the customer, no billing impact.

Use the **[Browser Terminal](/demos/browser-terminal)** to run these commands live during a call. Each script below includes talking points for what to say while the command runs.

---

## Choosing a script

| Script | Length | Best for |
|---|---|---|
| Browser Demo | 3 min | Cold calls, first meetings |
| The 5-Minute Network | 5 min | Discovery calls, executive intros |
| Cloud Connect | 10 min | Technical evaluations, pre-sales |
| Multi-Cloud Hub | 15 min | Deep-dive SA sessions |

---

::info-card{type="tip" title="Demo setup"}
Before your call:

1. Open the [Browser Terminal](/demos/browser-terminal) and connect with staging credentials
2. Run `megaport-cli status` to confirm you're authenticated
3. Use the copy buttons in each script to run commands without typing

If you have a staging account with existing resources, `megaport-cli status` and `megaport-cli ports list` will show real data — more compelling than an empty account.
::
