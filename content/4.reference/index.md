# Command Reference

Full documentation for all Megaport CLI commands.

## Command Groups

### Resources

| Command | Description |
|---|---|
| [`megaport-cli ports`](/reference/command-reference#ports) | Manage physical ports |
| [`megaport-cli vxc`](/reference/command-reference#vxc) | Manage Virtual Cross Connects |
| [`megaport-cli mcr`](/reference/command-reference#mcr) | Manage Megaport Cloud Routers |
| [`megaport-cli mve`](/reference/command-reference#mve) | Manage Megaport Virtual Edges |
| [`megaport-cli ix`](/reference/command-reference#ix) | Manage Internet Exchange connections |
| [`megaport-cli nat-gateway`](/reference/command-reference#nat-gateway) | Manage NAT Gateways |

### Discovery

| Command | Description |
|---|---|
| [`megaport-cli locations`](/reference/command-reference#locations) | Browse available locations |
| [`megaport-cli partners`](/reference/command-reference#partners) | Browse partner configurations |
| [`megaport-cli servicekeys`](/reference/command-reference#service-keys) | Manage service keys |

### Identity & configuration

| Command | Description |
|---|---|
| [`megaport-cli auth`](/reference/command-reference#auth) | Manage authentication and view current identity |
| [`megaport-cli whoami`](/reference/command-reference#whoami) | Display current authenticated identity |
| [`megaport-cli config`](/reference/command-reference#config) | Manage profiles, defaults, import/export config |
| [`megaport-cli users`](/reference/command-reference#users) | Manage users |
| [`megaport-cli managed-account`](/reference/command-reference#managed-account) | Manage partner managed accounts |
| [`megaport-cli billing-market`](/reference/command-reference#billing-market) | Manage billing markets |

### Operational

| Command | Description |
|---|---|
| [`megaport-cli apply`](/reference/command-reference#apply) | Provision multiple resources from a YAML/JSON file |
| [`megaport-cli status`](/reference/command-reference#status) | Show a dashboard of all Megaport resources |
| [`megaport-cli topology`](/reference/command-reference#topology) | Show resource relationship tree |
| [`megaport-cli product`](/reference/command-reference#product) | Manage products (cross-resource operations) |
| [`megaport-cli version`](/reference/command-reference#version) | Print the CLI version |
| [`megaport-cli completion`](/reference/command-reference#completion) | Generate shell completion scripts |
