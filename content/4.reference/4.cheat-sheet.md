# CLI Cheat Sheet

Copy any command below. For full details, see the [Command Reference](/reference/command-reference).

---

## Authentication

::command-example
---
command: export MEGAPORT_ACCESS_KEY=your_key MEGAPORT_SECRET_KEY=your_secret MEGAPORT_ENVIRONMENT=staging
description: Set credentials via environment variables (simplest approach)
---
::

::command-example
---
command: megaport-cli config create-profile staging --access-key $KEY --secret-key $SECRET --environment staging
description: Create a named config profile for reuse
---
::

::command-example
---
command: megaport-cli config use-profile staging
description: Switch to a saved profile
---
::

::command-example
---
command: megaport-cli whoami
description: Confirm which user, company, environment, and profile are active
---
::

---

## Apply (declarative IaC)

::command-example
---
command: megaport-cli apply -f infrastructure.yaml --dry-run
description: Validate a multi-resource YAML/JSON config without provisioning
---
::

::command-example
---
command: megaport-cli apply -f infrastructure.yaml --yes
description: Provision all resources (ports, MCRs, MVEs, VXCs) in dependency order
---
::

---

## Output Formats

::command-example
---
command: megaport-cli ports list --output json
description: JSON output for scripting
---
::

::command-example
---
command: megaport-cli ports list --output csv
description: CSV output for spreadsheets
---
::

::command-example
---
command: megaport-cli ports list --output json | jq '.[].name'
description: Pipe JSON to jq for filtering
---
::

::command-example
---
command: 'megaport-cli ports list --output json --query "[?provisioningStatus==''LIVE''].name"'
description: JMESPath query — filter LIVE ports without piping through jq
---
::

::command-example
---
command: 'megaport-cli ports list --output go-template --template ''{{range .}}{{.Name}}{{"\n"}}{{end}}'''
description: Custom one-line summary with a Go template
---
::

## Command Aliases

Most subcommands have short aliases for faster typing:

| Full command | Alias | Example |
|---|---|---|
| `list` | `ls` | `megaport-cli ports ls` |
| `get` | `show` | `megaport-cli ports show PORT_UID` |
| `status` | `st` | `megaport-cli ports st PORT_UID` |
| `delete` | `rm` | `megaport-cli ports rm PORT_UID` |
