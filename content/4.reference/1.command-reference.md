# Command Reference

Every command, subcommand, and flag in the Megaport CLI. For input modes (interactive, flags, JSON), see [Input Modes](/core-concepts/input-modes). For output formats, see [Output Formats](/core-concepts/output-formats).

---

## Global flags

These flags are available on every command.

| Flag | Short | Default | Description |
|---|---|---|---|
| `--output` | `-o` | `table` | Output format: `table`, `json`, `csv`, `xml` |
| `--env` | | | Environment: `production`, `staging`, `development` |
| `--profile` | | | Config profile to use for this command |
| `--verbose` | `-v` | `false` | Show additional debug information |
| `--quiet` | `-q` | `false` | Suppress informational output — show only data and errors |
| `--no-color` | | `false` | Disable colorful output |

## Authentication

Credentials are resolved in this order (highest priority first):

1. CLI flags (`--env` + profile credentials)
2. Environment variables: `MEGAPORT_ACCESS_KEY`, `MEGAPORT_SECRET_KEY`, `MEGAPORT_ENVIRONMENT`
3. Active config profile
4. Default values set via `config set-default`

See [Config Profiles](/core-concepts/config-profiles) for profile management.

## Ports

Manage physical ports. Most subcommands take a `portUID` positional argument.

| Command | Description |
|---|---|
| `ports list` | List all ports |
| `ports get <portUID>` | Get full port details |
| `ports status <portUID>` | Get port provisioning status |
| `ports buy` | Provision a new port |
| `ports buy-lag` | Provision a LAG (Link Aggregation Group) port. **Note:** LAG ports only support 1, 12, or 24 month terms (not 36). |
| `ports validate` | Validate port buy configuration without provisioning |
| `ports validate-lag` | Validate LAG port buy configuration |
| `ports update <portUID>` | Update port settings (name, cost centre, marketplace visibility) |
| `ports delete <portUID>` | Delete a port |
| `ports restore <portUID>` | Restore a recently deleted port |
| `ports lock <portUID>` | Lock port to prevent accidental deletion |
| `ports unlock <portUID>` | Unlock a locked port |
| `ports check-vlan <portUID>` | Check if a VLAN is available on a port |
| `ports list-tags <portUID>` | List resource tags on a port |
| `ports update-tags <portUID>` | Add or update resource tags |

```bash
# List ports, then get details on one
megaport-cli ports list
megaport-cli ports get abc123-def456
```

## Locations

Browse data centre locations on the Megaport fabric. Read-only — no UIDs required.

| Command | Description |
|---|---|
| `locations list` | List all locations |
| `locations get <locationID>` | Get details for a specific location |
| `locations search <query>` | Fuzzy search locations by name |
| `locations list-countries` | List all countries with Megaport presence |
| `locations list-market-codes` | List all market codes |

```bash
megaport-cli locations list --metro Sydney
megaport-cli locations search "NextDC"
megaport-cli locations get 3 --output json
```

## Partners

Discover partner ports available on the Megaport fabric. Read-only.

| Command | Description |
|---|---|
| `partners list` | List partner ports (supports filtering) |
| `partners find` | Interactive partner discovery |

**List filters:**

| Flag | Description |
|---|---|
| `--company-name` | Filter by provider name (e.g. `"Amazon Web Services"`) |
| `--product-name` | Filter by product/service name |
| `--location-id` | Filter by location ID |

```bash
megaport-cli partners list --company-name "Amazon Web Services" --location-id 3
megaport-cli partners list --output json
```

## Config

Manage CLI configuration, profiles, and defaults. See [Config Profiles](/core-concepts/config-profiles).

| Command | Description |
|---|---|
| `config view` | Display current config and active profile |
| `config create-profile <name>` | Create a new config profile |
| `config update-profile <name>` | Update an existing profile |
| `config delete-profile <name>` | Delete a profile |
| `config list-profiles` | List all profiles |
| `config use-profile <name>` | Set the active profile |
| `config set-default <key> <value>` | Set a default value (e.g. `output json`) |
| `config get-default <key>` | Get a default value |
| `config remove-default <key>` | Remove a default value |
| `config clear-defaults` | Remove all default values |
| `config export --file <path>` | Export config to JSON (credentials redacted) |
| `config import --file <path>` | Import config from JSON |

```bash
megaport-cli config create-profile staging \
  --access-key $STAGING_KEY \
  --secret-key $STAGING_SECRET \
  --environment staging

megaport-cli config set-default output json
megaport-cli config view
```
